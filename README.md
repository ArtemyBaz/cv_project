# Проекты OpenCV #
Данный репозиторий содержит несколько простых программ выполняющих разные задачи с помощью библиотеки OpenCV:
- cv_tanks - минни игра в танки
- robots - отслеживает роботов разных цветов на видео;
- sinusoid - рисование синусоиды
- thermal_imager - поиск горячих точек на изображениях с тепловизора
